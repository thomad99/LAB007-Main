The server renders a static 1-bit BMP of this customer’s hours for ESP32 + e-ink (no browser on device). The device checks a small JSON meta file for changes, then downloads the image only when the version changes. Default poll is 12 hours to save battery; you can set it lower for testing. Changing the poll here updates the device on its next check-in (no reflash required).
