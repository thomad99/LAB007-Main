ESP32 / e-ink static preview (1-bit BMP — same file the device downloads)

Tip: set e-ink size to 600×1024 under ESP32 / E-ink for a 1:1 match. PNG logos/gallery images dither best.

The server renders a static 1-bit BMP of your Design canvas for ESP32 + e-ink (no browser on device). Download ESP32 .ino embeds that BMP in firmware (DESIGN_BMP[]) so the panel can show your design offline, then keeps syncing newer designs/hours from the server when the version changes. Prefer e-ink size 600×1024 to match the tablet canvas (or set it to your panel resolution).
